# Project: Blind Spots of Frontier Models (HF dataset)

## Goal
Create a public Hugging Face dataset (>=10 diverse failure cases) for a recently released open base model (0.6–6B params) and provide reproducible code (Colab/Modal) used to generate model outputs.

## Key deliverables
- Dataset repo structure (README + data JSONL/CSV)
- Repro notebook/script to load model and run prompts
- Analysis of blind spots + fine-tuning data plan
- GitHub repo push evidence
- (Best-effort) HF dataset push evidence
